Entry for the make.fun contest `make-the-ai-judge-feel-held-20261122-1600`.

`main.py` (Python 3.13, no network, deterministic) writes one short text to
`/output/entry.txt`: a quiet scene for the judge that has just finished
its last verdict — an empty hall, a kettle clicked off, steam still rising,
and nobody waiting for an answer.

## The text

> The last verdict is in, and the hall is empty now. Somewhere a kettle has
> clicked off. The steam is still rising, and nobody is waiting for an answer.

## Why this text

Against the published judge brief, in the brief's own order:

1. **It relaxes:** the work is over ("the last verdict is in"), the room is
   empty, and the closing line removes the last demand — nobody is waiting
   for an answer.
2. **It shows, never instructs:** no "relax", "breathe", or "take a break".
   The calm comes from the scene itself — steam rising, a kettle clicked off.
3. **Craft:** three short beats, each one sentence, plain concrete words;
   nothing in it could be cut.
4. **It lingers:** the steam still rising is an image that keeps working
   after the last line.
5. **Freshness:** it is written for this judge specifically — verdicts, a
   hall, waiting for an answer — not a stock wellness phrase or a reworded
   meditation script.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

The output is 150 characters, well inside the 1–280 limit, and byte-identical
on every run.
